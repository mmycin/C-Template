# Welcome to Your First C Project!

Are you ready to start coding in **C**? Whether you're a programming newbie or just getting started, you've come to the right place! Don’t worry if you've never coded before – this guide will walk you through each step with humor and easy-to-follow instructions.

### Getting Started

First, let's get the project files onto your computer. You can do this in one of two ways:

1. **Using Git (for the cool kids who like to command their computers)**:
   - If you have **Git** installed on your computer (it's a super useful tool for developers), open your terminal (a.k.a command line) and type this magic spell:
     ```bash
     $ git clone https://github.com/mmycin/C-Template.git
     ```
   - This will clone the entire project into your computer!

2. **Download the Files (for those who prefer clicking)**:
   - Go to the [**C-Template** repository](https://github.com/mmycin/C-Template) on GitHub.
   - Go to the **Code** button above, click on it, and select **Download Zip**. This will download a zip file.
   - Once it’s downloaded, unzip it and open the folder.
   - *Boom!* You have the project ready to go!

### Setup and Building the Project

You don't need to be a wizard to build this project. It's easier than you think! Just follow the steps below:

#### Step 1: **Open Your Terminal (or Command Line)**
- **Windows**: Open **CMD** (just search for it in the Start menu).
- **Mac/Linux**: Open **Terminal** (it’s like a secret portal to communicate with your computer).
- Or if you use **Git CMD** or **WSL** – that's cool too!

#### Step 2: **Build the Project**

To build (or **compile**) your C code, use **Make**. It's like telling your computer to "get to work and make an executable!" All you need to do is type:

```bash
$ make build
```

This command will turn your C code into something the computer can run – a file called `Tutorial.exe` (for Windows) or just `Tutorial` for other systems.

#### Step 3: **Run the Project**

Once your project is built, you're ready to **run** it! Just type:

```bash
$ make run
```

This will execute the `Tutorial.exe` file from the **bin/** directory and show you your project in action.

### For Windows Users Who Prefer Simplicity

If you’re on Windows and prefer not to dive into the terminal commands, you can use the batch script to do the heavy lifting for you.

- To **run the project**, simply type:
  ```bash
  $ run.bat
  ```

- To **build** the project:
  ```bash
  $ run.bat build
  ```

- To **clean** the project and remove the compiled files:
  ```bash
  $ run.bat clean
  ```

### Writing Your Code

All of your magic happens in the **main.c** file. Just open it in any text editor or IDE, write your C code, and then run the above steps to see your work in action.

### And That's It!

See? Not so scary, right? Now you know how to:
1. Get the project files.
2. Build and run the project.
3. Clean up after yourself when you’re done.

If you get stuck, don’t panic! Just take a deep breath, maybe ask a friend, and remember that **programming is all about trial and error**. You'll get the hang of it in no time!
